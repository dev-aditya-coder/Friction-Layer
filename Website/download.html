INSTALLATION GUIDE

Up and running in a few steps.

When you have the extension project folder on your computer, use Chrome's developer mode to load it locally.

01

Get the extension files

Obtain the Friction Layer extension project folder from your team or project repository. It should contain a manifest.json file.

02

Open Chrome extensions

In Google Chrome, visit chrome://extensions from the address bar.

03

Turn on Developer mode

Enable the Developer mode switch near the top-right of the extensions page.

04

Load the unpacked folder

Select Load unpacked, then choose the extension folder containing manifest.json.

05

Pin the extension

Open Chrome's puzzle-piece menu and pin Friction Layer so it is easy to access.

06

Try it on YouTube

Open YouTube and test supported filtering features. Review the results carefully; relevance scoring can make mistakes.

⌘

Before you begin

This site is the onboarding interface. It does not contain the extension package itself, and a Chrome Web Store link has not been configured.

  • Use a desktop version of Chrome for this setup.
  • Keep the extension folder in a location you won't move.
  • Reload the extension after changing its code.

PRIVACY & TRANSPARENCY

Your choices should stay your choices.

This website stores customization preferences in your browser's local storage. At this prototype stage, it does not send those settings to the extension. Don't treat this as a verified privacy audit of the extension code.

NEED A HAND?

Quick answers.

Why can't I download it directly here?

The extension package and verified store listing have not been attached to this website yet. This page intentionally avoids linking to a fake download.

Will my website preferences automatically sync to the extension?

Not yet. The website currently saves preferences locally. Syncing them requires a real integration between the site and extension.

Does it work inside the YouTube mobile app?

No. A browser extension generally cannot modify the native YouTube app. This prototype is designed for supported desktop browser pages.

What if the extension doesn't appear?

Confirm you selected the folder containing manifest.json, check for errors on chrome://extensions, then use the Reload button after code changes.
